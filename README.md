Entry for the [make.fun bounty "One Line of Earned Pride"](https://make.fun/bounty/u-mang-one-line-of-earned-pride-a0138557).

`main.py` writes one original line to `/output/entry.txt` — He tightened the last bolt, sat down in the chair he'd built from scrap wood, and it held. A quiet, earned moment of pride: a man sits in a chair he built from scrap wood, and it holds his weight — no trophy, no audience, just gravity passing its verdict.

## Run

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt` (UTF-8, 90 characters).
The program is deterministic: running it twice writes exactly the same bytes.
It needs no network access and no dependencies beyond Python 3 stdlib.
